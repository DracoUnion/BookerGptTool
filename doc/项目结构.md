# BookerGptTool 代码结构

BookerGptTool 是一个基于 OpenAI 兼容 API 的命令行工具集，当前提供模型调用、批量检查、自由推理和 API 转发服务。

命令行入口两个：`BookerGptTool` 与 `gpt-tool`，均映射到 `BookerGptTool.__main__:main`（pyproject.toml `[project.scripts]`）。`__main__.py` 构建顶层 `argparse` 解析器（含 `-m/--model`、`-k/--key`、`-H/--host`、`-r/--retry` 等通用 LLM 参数），注册 `call`、`infer`、`forward` 三个子命令，最后 `args.func(args)` 派发执行。

代码全部位于 `BookerGptTool/` 包内，按职责分为三类模块：

## 1. 入口与包元信息

+ `__main__.py` — 唯一 CLI 入口。构建顶层 `argparse` 解析器（通用 LLM 参数：`-m/--model`、`-k/--key`、`-H/--host`、`-r/--retry`、`-tm/--temp`、`-ST/--no-stream`、`-D/--debug` 等），注册 `call`/`infer`/`forward` 三个子命令的 `reg_subparser`，最后 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.3.25.0，SATA 协议，作者 wizardforcel）。

## 2. 共享基础设施

+ `openai.py` — LLM 客户端层：`OpenAIClient` 类（`call_llm`、`call_llm_retry`、`ask_chatgpt_retry`、`call_vlm_retry`、`call_tti`、`call_tti_retry`、`call_llm_with_toolcall_retry` 等），`ToolsMixin` 工具调用混入，`base_schema`/`func_schema`/`model_schema`/`str_list_schema`/`str_str_map_schema` 等 function-calling Schema 构造助手。
+ `util.py` — 通用工具函数，跨命令复用：文本块提取与替换（`ext_code_block`/`repl_code_block`/`rec_code_block`、`split_md_lines`/`group_chunks`）、提示词渲染（`render_prompt`）、模型序列化与缓存（`json_dump_model`/`json_load_model`/`write_yaml_model`/`read_yaml_model`）、文本相似度（`ngram_jaccard`/`ngram_coverage`）、文件与路径工具（`read_text`/`write_text`、`md5`/`gen_objs_md5`/`extname`）。

## 3. 三类子命令模块

+ `call.py` — `call` 子命令：自定义问题调用模型并输出回答（`call_handle`）；`check_batch_handle` 用于检查 YAML 文件中的 key，适合在批量处理前做结构校验。
+ `infer.py` — `infer` 子命令：自由推理（`tr_infer`，读取问题文件并执行推理）。
+ `forward.py` — `forward` 子命令：OpenAI 兼容 API 转发服务（`forward`，内置请求处理与流式 `generate`/`handle_ex`，监听端口转发模型请求）。

## 4. 模块约定

每个子命令模块均提供 `reg_subparser(subparsers)` 注册参数并绑定对应的 `xxx(args)` 入口函数，在 `__main__.py` 中被逐一调用注册；LLM 调用统一走 `openai.py` 的 `OpenAIClient`，通用文本/模型工具统一走 `util.py`。

仓库中目前无 `tests/` 与 `doc/` 子目录（本文档为新建）。
